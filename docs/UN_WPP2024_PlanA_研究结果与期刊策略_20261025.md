# 方案A：使用联合国WPP 2024独立人口数据核查GBD2023中国—G20参照国构成

日期：2026年10月25日；研究：1990–2023年、19个G20主权国家、女性15–49岁，七个五岁年龄组。**已下载官方UN WPP原始CSV，并完成GBD原始数据重新计算。**

## 主要发现

| 指标（每10万女性） | GBD2023人口权重 | UN WPP2024人口权重 |
|---|---:|---:|
| PCOS相关总不孕，1990中国－参照国率差 | -272.92 | -273.31 |
| PCOS相关总不孕，2023中国－参照国率差 | -121.38 | -122.62 |
| 1990—2023率差变化 | +151.54 | +150.69 |
| 对称分解中“参照国家人口份额变化”贡献 | +88.65 | +86.76 |
| 上述人口份额贡献/净率差变化 | 58.5% | 57.6% |
| 2023 PCOS相关继发不孕中国－参照国率差 | +2.16 | +2.26 |
| 2023内异症相关总不孕中国－参照国率差 | -0.20 | -0.03 |

**结论1：核心人口构成效应被不同人口数据源复算后保留。** 即使使用联合国独立人口估计，仍有约+86.76/10万人（净变化的57.6%）来自参照国构成变动。与GBD自身人口的+88.65（58.5%）数值接近，但**UN不提供不孕率，不能称为GBD疾病模型的独立验证**。

**结论2：接近零的继发不孕比较不稳定。** 用联合国2023年人口份额比较时，中国比18国参照高+2.26/10万人；若将18国权重固定在1990年则为-48.34/10万人；各国等权时为-127.89/10万人。不同方案代表不同参照目标，并不互相构成误差或置信区间。

**结论3：人口份额结构确实改变。** 联合国人口估计显示，参照国中印度的年龄加权份额由1990年的35.71%升至2023年的46.45%。这不是印度不孕风险增加的证据；只是选定18国人口规模相对变化。

**结论4：2023年内异症总不孕的所谓“趋同”仍不稳定。** UN权重下2023年率差-0.03，但2022年是-8.61；模型尾年突变并未得到独立的临床发病率确认。

## 方法学要点

- 以GBD原始Numbers/GBD人口估计计算各国各年龄不孕率，所有联合国敏感性分析**保留原GBD不孕率不变**。
- 仅以UN PopulationByAge5GroupSex_Medium中每年龄、每年、每国女性人口重新求其在18国参照人群中的份额。
- 15–49岁的七个年龄标化权重始终使用相同的、重新归一化的GBD标准权重；没有把联合国人口当作疾病率分母。
- 利用对称恒等分解将中国率变化、参照国率变化、参照国人口份额变化的贡献严格相加核对；还完成末年2021/2022/2023、1990年固定国家份额、各国等权、逐国删除等敏感性分析。
- UN WPP文件及筛选数据SHA-256保存在manifest；19×34×7=4,522个匹配人口单元完整；每种病因的原发+继发=总量核验通过。
