# 结果解读与投稿前研究审查

这是基于真实GBD2023数据的描述性研究草稿，尚未投稿。分析覆盖19国、1990–2023年、女性15–49岁、两病因及总/原发/继发不孕，主要指标为年龄范围内标化患病率。

## 有据可写的结果

1. 中国PCOS相关总不孕ASPR由333.56升至605.08/10万，参照由606.48升至726.45；比值0.550升至0.833。所有逐国剔除分析中，总差值仍为负。
2. 总差值掩盖分型：中国2023年PCOS原发不孕ASPR97.35，参照220.89；继发为507.72与505.56。1990–2023年总差值变化的69.4%对应继发分型。继发的+2.16/10万很小，且对参照组成敏感，不能宣称已明确超过参照。
3. 中国PCOS相关不孕人数净增加783,425；年龄别患病水平项+860,721，15–49岁女性总人口项−68,426，年龄结构项−8,869。这是数学归因，不能等同于肥胖或生育政策等机制的因果归因。
4. 内异症2023年总差值−0.20，包含原发−7.94与继发+7.73相互抵消。2022年总差值为−8.76；2023年末年跳变使长期差值变化的方向发生改变，因此不适合以“稳定收敛”为题。
5. 所有复杂预测候选均未满足七年龄组及两种验证方案中稳定优于末年率基线的条件。论文报告失败回测，不制造2035年预测病例。

## 不能由现有数据推出的结论

- 无联合匹配draws，不能提供派生率、差值、分解项的有效GBD联合UI；原始边际区间不能直接相加。主分析为点估计。
- 趋势区间只反映给定拐点、给定GBD点估计后的模型拟合，不表示全流程不确定性。
- 不将较低患病率解释为较好诊疗，不将基准差额称作可避免病例。
- 不能证明2023年的内异症跳变是真实突发流行变化；独立资料或IHME解释仍有价值。

## 投稿定位

Lu 2026及Xu 2025已有高度相近结局研究，2026年BRICS/G7研究也使用GBD2023及类似趋势/分解框架。本稿的潜在贡献在于分型和年龄维度揭示的抵消、先合并年龄别分子分母的参照构造、以及终点敏感性，而不是单纯增加国家或年份。

中科院二区及以上是目标，当前分区未核验，也不保证录用。正式投稿前需要实际作者完成作者/单位、通讯、贡献、基金、利益冲突、伦理认定和AI使用披露，并审查创新性与GBD不确定性限制。外部NSFG验证和未来人口情景是可选扩展，本轮未实施。
