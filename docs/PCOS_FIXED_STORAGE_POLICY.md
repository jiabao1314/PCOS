## Required checks for every run
1. Check whether each requested source/output already exists; do not unnecessarily redownload or overwrite.
2. Validate original metadata, data labels, hashes, denominators, age weights and analyses; document exploratory post-hoc changes and citations.
3. Verify cloud readback and exact destination before saying that any upload was completed.
4. If Galaxy is read-only in the active chat, prepare a Galaxy-ready file and a pending-upload manifest in Drive, **clearly mark that Galaxy upload has not happened**, and retain Galaxy PCOS as the upload destination.
5. Do not equate GBD marginal uncertainty intervals, independent-survey confidence intervals, country bootstrap, or arbitrary simulations with jointly indexed GBD posterior draws.
6. Preserve legal provider terms, scientific reproducibility, participant privacy and ethical review. Public GitHub should contain permitted code and aggregate or derived outputs, not restricted raw data.

This workflow preference is part of the project record and is intended to be reused in future PCOS analyses.
