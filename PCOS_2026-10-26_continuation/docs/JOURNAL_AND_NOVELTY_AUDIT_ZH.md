## 新增计算对结论的影响

所有下列值都是GBD模型点估计，没有传播联合不确定性；率差单位为每10万女性，年龄权重在15–49岁内归一化。

- PCOS的中国减参照差值从−272.92变为−121.38，变化+151.54。对称分解为中国率变化+271.51、参照国率变化−208.62、参照国份额变化+88.65。份额项为净变化的58.5%；其余率项净值为+62.89。
- 份额项在2021、2022终点仍为正，分别为+88.11和+86.74。2023逐国剔除及20–49岁敏感性中的份额占比为39.8%–67.9%，因此只能说“有实质贡献”，不能说所有设定均“超过一半”。
- 继发不孕对应总差值变化的69.4%；2021/2022终点为70.5%/69.0%。2023逐国剔除及年龄范围改变后为64.2%–75.4%，固定1990参照国份额后为78.1%。继发是较大的正向贡献较稳定，精确百分比依赖设定。
- 2023年PCOS原发差值−123.54在逐国剔除后仍为负；继发差值+2.16的方向不稳定（−113.63至+30.72）。不能将接近持平解释为稳健的正向差异。
- 69.4%按不孕类型划分，58.5%按变化组成划分，两者相交，**不可相加**。
- 内异症2023原发−7.94、继发+7.73相抵，但2022总差值−8.76，与2023的−0.20相差很大。该末年现象没有外部验证，不作为“已证实趋同”的主结论。

新增脚本为 `src/reference_composition.py`，输出完整国家剔除、年龄、1990/2010起点及2021/2022/2023终点表。每个分解均核对总和恒等式，全部类型核对原发+继发=总量，并与原有独立比较流程交叉核验。该分析是在稿件评估时新增，已在方法中明确标为事后分析。

## 已按Reproductive Health完善的内容

依据该刊[Research要求](https://link.springer.com/journal/12978/submission-guidelines/research)和[通用格式](https://link.springer.com/journal/12978/submission-guidelines)：采用四段式摘要（少于350词）、独立Plain English summary（少于250词）、8个关键词、规定正文层级、缩略语表、完整Declarations小标题、Methods中的AI使用说明、顺序编号参考文献、双倍行距及行页码。主稿不含手动分页；图为独立矢量PDF，表保持可编辑，正文和补充材料分开。机器可读结果及源码组成Additional file 2。

正文减少次要方法堆积，将有条件趋势区间、未通过验证的预测、病例数分解和详细审计移至Additional file 1；没有为了丰富结果而保留未通过验证的未来预测。图表标题和说明按刊物长度限制检查。封面信形成作者可完善的草稿，不擅自写入“全体作者已同意”或“未同时投稿”等未知事实。

该刊官网当前APC为€2990 / US$3390 / £2590，另计适用税费，以录用时价格为准；机构协议或减免须符合实际条件。本次没有支付费用或提交论文。首轮决定中位时间不是录用时间，往期GBD论文也不构成未来接收承诺。[费用及政策](https://link.springer.com/journal/12978/submission-guidelines)

结论：本次修改提高了问题集中度、结果可解释性和格式合规程度；在缺少联合不确定性与外部验证的情况下，仍应将它定位为有明确增量、但存在初筛风险的GBD生态学二次分析，而非保证中科院二区以上录用的论文。

## 外部证据补强后的更新

新增独立NSFG调查分析、GBD输入来源重叠审计和R survey核对，详见[DRAWS与外部检验报告](DRAWS_AND_EXTERNAL_VALIDATION_ZH.md)。检索新增Liu等2026年GBD2023加中国临床系列研究（doi:10.2147/IJWH.S622604），因此“GBD加外部病例”也不能作为首次创新。现稿外部资料定位为测量三角验证；共同病因归因、联合不确定性和中国人群外推的不足仍存在。原报告中的“缺少外部资料”应理解为缺少与GBD中国病因率匹配的独立验证，而不是本轮仍未分析任何外部数据。
