# PCOS / GBD 共享项目概览

最后更新：2026-10-29T17:10:17+01:00

研究目标：PCOS相关不孕的国际比较、比较基准与估计目标辨析，形成高质量SCI论文；中科院一区是争取目标，不是已核实的投稿资格或录用承诺。当前已有 Reproductive Health 备选修订稿。最新工作包为 `PCOS_Revision_2026-10-29/`；医院可行性为独立分支 `PCOS_Hospital_Feasibility_2026-10-29/`。

数据：GBD 2023，1990–2023，女性15–49岁七年龄组，中国与另外18个G20主权国家；PCOS与内异症相关不孕，总体/原发/继发。不是所有PCOS患病率，也不是医院就诊人群的国家推断。UN WPP 2024用于参照国年龄内人口份额替换；NSFG2022–2023属于早期美国外部三角证据模块，未纳入当前聚焦稿。

技术路线：核验原始输入哈希及完整网格→按年龄先合并参照国家，再按统一七年龄权重标化→比较中国与参照的率差/率比→对率差变化作对称三因素分解（中国率、参照国率、参照国构成）→R/Python独立核对→终点/年龄范围/固定1990份额/等国家权重/逐国剔除/UN份额敏感性→正文、补充和可复现包。

估计目标：描述性年龄标化病因特异不孕率差及其变化的恒等式分解。动态、固定、等权参照回答不同问题，不能任意换用；同人口基准不是可避免病例或因果干预效应。UN替换保留GBD率，不是临床外部验证。分解创新在识别参照构成对比较结论的影响；创新程度、分区与期刊适配仍需按投稿时证据评估。

证据：`PCOS_Revision_2026-10-29/README.md`、`docs/revision_analysis_qc.json`、`docs/RESPONSE_TO_REVIEW_2026-10-29.md`；历史 `docs/PROTOCOL_ZH.md`、`docs/STATUS.md`、`docs/DRAWS_AND_EXTERNAL_VALIDATION_ZH.md`。不复制历史大包，不移动数据。

限制：尚无经确认联合对齐的GBD posterior draws；派生差值/分解只作点估计，不能将边际UI拼为联合区间。医院样本用于既有数据内的临床妊娠可行性研究，不能校准国家患病率；尚未完成临床建模。伦理审批状态未确认，研究使用许可已确认。XX投稿字段留给用户。

存储：原始研究下载进既有Galaxy PCOS；许可原件留档。代码/许可允许的汇总结果/论文双存Drive与GitHub。敏感医院原件只留既有私人位置。见DECISIONS。
