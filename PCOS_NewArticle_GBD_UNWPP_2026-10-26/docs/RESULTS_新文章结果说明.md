# 组会结果说明

采用最新投稿准备稿的科学主线：参照人口构成如何改变中国与其余18个G20国家的不孕负担比较。分析使用1990—2023年、女性15—49岁、七个五岁年龄组，PCOS和内异症病因归因不孕按总计、原发和继发分层。率差统一为中国减参照，每10万女性；均为GBD模型点估计。

## 结果1：两套人口权重下的主要分解结果接近

| PCOS相关总不孕 | GBD人口权重 | UN WPP人口权重 |
|---|---:|---:|
| 1990率差 | -272.92 | -273.31 |
| 2023率差 | -121.38 | -122.62 |
| 率差净变化 | +151.54 | +150.69 |
| 中国率变化贡献 | +271.51 | +271.51 |
| 参照国率变化贡献 | -208.62 | -207.59 |
| 参照人口构成贡献 | +88.65 | +86.76 |
| 构成贡献／带符号净变化 | 58.5% | 57.6% |

更换人口来源后，人口构成贡献仍接近58%，支持参照构成影响的稳健性。构成贡献衡量参照结构变化，不能解释为疾病病因或医疗改善。

对称分解将两个替换顺序平均，三项严格加总为净率差变化。年度链式敏感性中，GBD人口构成贡献为+87.11（57.5%），UN为+86.83（57.6%）。这些是记账路径敏感性，不是后验不确定性。亚型69.4%贡献与构成58.5%贡献是相交维度，不能相加。

## 结果2：继发不孕率差的方向随基准变化

| 2023年PCOS相关继发不孕的UN参照基准 | 中国减参照率差 |
|---|---:|
| 当年人口权重 | +2.26 |
| 固定1990人口权重 | -48.34 |
| 国家等权 | -127.89 |

同一组疾病率在三种参照定义下产生不同方向的比较结果，不能据当年权重下的微小正值宣称中国已稳定超过参照国家。三个基准回答不同问题，不能把其范围视为置信区间。

## 结果3：内异症的2023近零差值依赖末年

| 内异症总不孕，GBD人口权重 | 中国减参照率差 |
|---|---:|
| 2021年 | -8.45 |
| 2022年 | -8.76 |
| 2023年 | -0.20 |

中国内异症标化率由2022年的43.13升至2023年的53.30，增幅约23.6%，使末年率差接近零。该末年变化缺少独立病因资料解释，不能直接据此宣称长期收敛。

## 实际复算核验

Python与base R分别读取原始GBD和UN输入，独立重算1,224条年度比较、36条端点分解、216条逐国剔除以及12条年度链式分解。两种语言结果最大绝对差约5.7×10⁻¹³，低于预设1×10⁻⁸检查阈值；前3张表亦逐项匹配新稿研究包。1,064个独立官方端点Rate单元复核通过；原发加继发重现总计。

这是实现与提取一致性检查，不能消除GBD上游估计偏倚，也不能代替外部疾病流行病学验证。联合draws缺失，全部自定义率差和分解继续仅作点估计。UN人口检查参照权重敏感性，不验证疾病患病率。
